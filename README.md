# 🎉 Birthday App for Your 8-Year-Old! 🎉

A fun, interactive birthday celebration app designed specifically for an 8-year-old's special day!

**[click here to demo](https://mrfeixiang.github.io/daughter-birthday-apph**

## Features

### 🎈 Interactive Games
- **Balloon Pop Game**: Click to pop colorful balloons and watch them burst!
- **Candle Blowing Game**: Blow out all 8 birthday candles by clicking them

### 🎊 Special Effects
- Confetti animations when clicking the surprise button
- Floating balloons with smooth animations
- Random sparkles that appear around the screen
- Bouncing birthday title

### 💝 Birthday Wishes
- Beautiful wish cards with encouraging messages
- Colorful, child-friendly design
- Responsive layout that works on tablets and phones

## How to Use

1. Open `index.html` in any web browser
2. Click the "Click for a Surprise!" button for confetti and birthday messages
3. Play the balloon popping game by clicking the balloons
4. Blow out the birthday candles by clicking each one
5. Enjoy the colorful animations and birthday wishes!

## Technical Details

- Pure HTML, CSS, and JavaScript (no external dependencies)
- Mobile-friendly responsive design
- Comic Sans font for a playful, child-friendly look
- Smooth animations and transitions
- Interactive games with score tracking

## Customization

You can easily customize the app by:
- Changing colors in `styles.css`
- Adding more birthday wishes in the HTML
- Modifying the games or adding new ones in `script.js`
- Adding the child's name to personalize the experience

Perfect for making a special 8th birthday even more memorable! 🎂✨
